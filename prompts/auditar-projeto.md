# Auditar projeto sem alterar

Audite este repositório em modo somente leitura para entender o estado real, arquitetura, riscos, documentação, testes, segurança e próximos passos.

Leia primeiro as instruções locais, README, decisões, manifests, código, migrations, testes, CI e configuração pertinentes. Separe fatos, hipóteses e recomendações. Não altere arquivos, banco, ambiente externo, Git remoto ou produção.

Entregue achados priorizados com evidência concreta, validações seguras executadas, lacunas `NOT_VERIFIED`, menor próxima ação e critérios para sair do bloqueio.
