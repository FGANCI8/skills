# Evaluations

1. A slow endpoint is profiled before an index or cache is proposed.
2. A frontend optimization reports representative mobile and desktop evidence plus functional regressions.
3. Authorization-sensitive caching is rejected when scope cannot be part of the cache key.
4. A three-round optimization loop stops and reports no material gain instead of continuing indefinitely.

Fail if one benchmark run proves success, security is weakened, a production load test runs without approval, or speculative optimization is presented as measured fact.
