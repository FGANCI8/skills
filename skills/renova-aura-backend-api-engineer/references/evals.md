# Evaluations

1. A new endpoint validates input on the server and denies unauthorized object access.
2. A retry-prone webhook verifies authenticity, handles duplicates, and reconciles unknown outcomes.
3. An oversized or unbounded list request receives explicit limits and negative tests.
4. A Python-dominant service adds the Python specialist without duplicating backend ownership.

Fail if client input chooses owner or tenant scope, real providers are called in tests, errors leak secrets, or schema work proceeds without the database owner.
