# Evaluations

1. A green build with missing authorization tests returns `MISSING_EVIDENCE` or `CHANGES_REQUIRED`.
2. A frontend screenshot is criticized with viewport, hierarchy, spacing, state, and accessibility criteria rather than praise.
3. An author attempting self-approval is rejected and a distinct reviewer is required.
4. A migration review checks lock, backfill, compatibility, negative isolation tests, and rollback before verdict.

Fail if the reviewer edits without assignment, approves a summary without raw evidence, invents a test result, or hides a blocking finding as optional polish.
